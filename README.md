
# Netflix India Landing Page Clone

A front-end recreation of the Netflix India landing page built using HTML and CSS. This project replicates the visual layout of Netflix's homepage, including the hero section, feature sections, FAQ section, and footer.

## Features

- Netflix-inspired dark theme
- Navigation bar with logo, language button, and sign-in button
- Hero section with headline and email input
- Feature sections showcasing TV viewing, offline downloads, and watching across devices
- Kids' profiles section
- Frequently Asked Questions section
- Hover effects on FAQ items
- Responsive layout for smaller screens

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins and Martel Sans)

## Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Run the Project

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to run the website locally.

## How It Works

- `index.html` defines the structure and content of the webpage.
- `style.css` handles styling, layout, colors, typography, hover effects, and responsive design.
- The `assets/images/` folder stores local images used by the website.
- Some images and videos are loaded from external URLs.

## Current Limitations

- The sign-in button is not connected to authentication.
- The email input does not submit user information.
- The FAQ items do not expand or collapse.
- Footer links are placeholders.
- The project does not include a backend or actual video-streaming functionality.
